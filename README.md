# Sprout 2.0 — UI/UX Design Assignment

## Project Overview
Sprout 2.0 is a mobile-first fintech app concept designed to make investing easier for beginners through a simple, friendly onboarding experience.

## Key Screens
- Welcome screen
- Account creation
- OTP verification (demo mode)
- Personal details
- KYC demonstration
- Success screen
- Investment dashboard
